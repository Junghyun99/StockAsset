# MDD Dip Signal Design

## Goal

급등 후 조정으로 200일 이동평균선과의 이격은 작지만 고점 대비 낙폭이 큰 경우에도, RSI 필터를 유지한 채 Stage 1~3 분할매수 캠페인을 시작한다.

## Decision

신호 계산기에 종가 기준 최근 252거래일 최고가 대비 최대낙폭(MDD)을 추가한다. 각 매수 단계는 기존 RSI 조건과 함께, 기존 200일선 이격도 또는 MDD 임계값 중 하나를 충족하면 진입한다.

| Stage | RSI | 200일선 이격도 또는 MDD | 목표 비중 |
| --- | --- | --- | --- |
| 1 | <= 48 | <= -10% 또는 <= -20% | 40% |
| 2 | <= 42 | <= -18% 또는 <= -30% | 60% |
| 3 | <= 36 | <= -26% 또는 <= -40% | 80% |

매도 조건, 트랜치 수, 기존 캠페인의 상태 전이 방식은 바꾸지 않는다. MDD가 새로 신호를 만들더라도 기존 Stage 1~3 캠페인 생성 및 체결 후 트랜치 소진 로직을 그대로 사용한다.

## Data and Observability

MDD는 `price / trailing_252_day_peak - 1`로 계산한다. 필요한 최소 일수는 기존 250일을 유지한다. 신호 구조체, 엔진 의사결정 요인, 저장되는 실행 요약에 `mdd_252`를 포함해 실제 진입 근거를 확인할 수 있게 한다.

## Tests

계산기는 252일 고점 기준 MDD를 정확히 반환하고, 데이터 부족 시 NaN을 반환해야 한다. 플래너는 RSI가 충족된 상태에서 MDD만으로 Stage 1~3으로 진입하는 경우와, RSI가 불충족이면 MDD가 커도 IDLE인 경우를 검증한다. 기존 이격도 기반 진입과 매도는 회귀 테스트로 유지한다.
